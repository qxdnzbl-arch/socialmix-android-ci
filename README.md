# 可话 Android 工程

这是“可话”复活工程的 Android + 公网后端候选，不是 SocialMix。

当前真实状态：
- Android applicationId: `com.qxdnzbl.kehua`
- 启动 Activity: `KehuaActivity`
- App 名称: `可话`
- 核心数据走公网 Supabase 后端，不用本地假数据冒充
- GitHub Actions 会实际构建 APK，并在 Android 35 模拟器安装、启动和执行工程验收

尚未满足的最终完成条件不得写成已完成：
- 用户确认的停运前最终原版视觉与交互高保真
- iPhone/iPad、Windows、macOS 正式安装包与同账号跨端实测
- 正式商店分发与真实商业化收款

任何旧 SocialMix、旧网页壳或历史实验版本都不得作为“可话最终版”交付。
