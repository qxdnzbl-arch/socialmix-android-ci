# 同频 · 2026-10-17 可部署测试版

## 目的
个人使用的手机 GPT + Claude 单窗口聊天应用。普通问题 GPT 单次回复；复杂问题后台 GPT→Claude→GPT 三次真实调用，必须在 302.AI 有余额、限额密钥已核验后才能真实验收。

## Vercel Hobby 安装
- 仅适用于**个人、非商业**用途。Vercel Hobby 有配额，触顶可能暂停，不是长期正式运营的高可用保证。
- 部署时选已存在的公开仓库 `qxdnzbl-arch/socialmix-android-ci`、分支 `tongpin-render-20261017`、**Root Directory: `tongpin`**、Framework: Other。不要修改默认 main，也不要指向其它项目。
- 免费层须检查是否包含函数运行以及官方免费使用范围。项目结构：`public/` 静态页面、`api/status.js`、`api/chat.js` 服务端入口。
- 未提供秘钥时允许网页加载，但发送必须拒绝；不暗中模拟 GPT/Claude 答复。
- 服务器环境变量：`AI302_API_KEY`（仅302.AI新建且**总配额、每日配额都有限制**的密钥）、`TONGPIN_ACCESS_PASSWORD`（专门设置的至少12位高强度密码）、`TONGPIN_LIMITED_KEY_VERIFIED=1`（只有操作者**实际核验**302.AI配额后方可设置）。全部在托管平台的 Secret/Environment Variables 中保存，**不写入仓库或聊天**。
- **不要使用302.AI当前存在的无限额密钥；不要自动充值。**当前用户302.AI余额0，真实收费调用不能测试。
- `npm test` 复核模拟模型接入和Vercel请求适配；本地经过12项测试。部署后必须实际检查HTTPS网址、/api/status、无密钥/错误密码时请求被拒绝、手机交互、账号保护，才能进一步上线。
- 服务端默认按不超过三次模型请求执行；费用估算不等于实际费用。函数内存计数在Vercel serverless实例间**不共享，不能当日度费用硬上限**，以302.AI密钥配额为准。
- Vercel函数最长配置180秒（Fluid Compute配置相关），代码总超时160秒；上游已接收的请求即使后续超时也可能扣费，客户端不能自动重试。
- **聊天历史目前只保留当前设备浏览器 localStorage**。第二台手机不会自动同步。正式满足多手机要求需要后端账号、同步数据库、加密和恢复方案，不能把现在版本宣称为已完成。
- **第三方隐私：**消息通过Vercel服务器和302.AI再转发给模型供应商，不建议在试验版发送个人敏感秘密。
- **长期维护：**托管平台/免费额度/302.AI价格和模型供给随时间可能变化。正式运营需要持久化存储、异常告警、数据导出/恢复、容量和费用控制、可迁移部署，不得以“当前有链接”替代这些要求。
